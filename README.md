# Astro watch face

Watch Face Format (v2) watch face for the Galaxy Watch 8 Classic (Wear OS 6), modelled on an
astronomy / outdoor concept: moon phase, weather, elevation, tide, ISS, deep-sky, sun and compass.

* `watchface/` – the watch face (resources only). `res/raw/watchface.xml` and all images are
  generated by `tools/gen.py` (Pillow), which also draws the background art.
* Regenerate: `python3 tools/gen.py watchface/src/main <dir with Barlow ttf files>`
* Every push builds on GitHub Actions, validates the XML with Google's validator and publishes the
  APK as the `latest` release.

Install: Wireless debugging on the watch, then `adb install AstroWatchFace.apk`.

Font: Barlow (SIL Open Font License, see `tools/Barlow-OFL.txt`).
