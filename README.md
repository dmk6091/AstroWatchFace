# Terra watch face

Astronomy / earth-science watch face for the Galaxy Watch 8 Classic (Wear OS 6, Watch Face Format v2),
deep-space colours, big readable values.

* **Centre:** live Earth globe centred on you, real day / night line with city lights, and the sun's
  path across your sky from sunrise to sunset.
* **Top:** date, sunrise / sunset, time.
* **Left:** weather icon + temperature, rain chance, humidity, AQI.
* **Right:** moon phase + % lit, moon age, altitude (barometer), day length.
* **Bottom panel** (tap it for the next screen): tide (place, height, rising / falling, curve,
  next high / low) → earthquakes (strongest M4.5+ of the last 24 h, timeline, count, nearest) →
  rain in the next 2 h (15-min bars; comes up by itself when rain is under 30 min away).
* **On the globe:** earthquakes of the last 24 h as red rings (USGS), the Moon over the place where
  it is overhead (with its phase), the ISS, the sun's glow.
* **Along the edge** (9 and 3 o'clock): UV index, sea-level pressure (watch barometer) with its 3-hour change;
  sun direction and where the watch points (compass, read when the face refreshes).
* Thin battery ring around the edge.

Parts:

* `watchface/` – the face (resources only). Everything is generated by `tools/terra.py`
  (Pillow): background art, moon phases, weather icons, `watchface.xml`, preview, and the shared
  field layout written into the companion's `FieldSpec.java`.
  Regenerate: `python3 tools/terra.py watchface/src/main <dir with Barlow ttf files>`
* `companion/` – "Astro" app on the watch. Complications: *Astro data* (one long text with
  fixed-width fields), *Astro globe* and *Astro tide graph* (pictures). Weather details, AQI and tide
  from Open-Meteo every 30 min; sun / moon calculated on the watch; altitude from the barometer.
* `tools/globe.py` – the globe maths (the companion's `Globe.java` is the same in Java).

Every push builds on GitHub Actions, validates the XML with Google's validator and publishes both
APKs as the `latest` release.

Updates: the Astro app on the watch updates itself and the face from that release
(*Update now*, plus *Auto-update* every few hours). First install with Wireless debugging
(GeminiMan, Bugjaeger or adb); if the watch has no "install unknown apps" switch for Astro, run once:
`adb shell appops set com.dmk.astrocompanion REQUEST_INSTALL_PACKAGES allow`.
The first face update asks for one tap on the watch, later ones are silent.

Credits: Barlow font (SIL OFL, `tools/Barlow-OFL.txt`); Earth textures from the three.js examples
(NASA Blue Marble / Black Marble based).
